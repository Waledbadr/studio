# 📊 بيانات عمال تجريبية

## الملف: `workers-sample.json`

هذا الملف يحتوي على **5 عمال** كمثال لاختبار نظام الاستيراد.

---

## 📋 محتوى الملف

### العامل 1: أحمد محمد السعدي
```json
{
  "name": "أحمد محمد السعدي",
  "employeeId": "40097",
  "idNumber": "2059537999",
  "company": "الشركة الأولى",
  "nationality": "سعودي",
  "role": "Worker"
}
```

**الملاحظات:**
- رقم وظيفي: 40097
- رقم هوية: 2059537999 (10 أرقام ✅)
- شركة: الشركة الأولى

---

### العامل 2: محمد علي الأحمد
```json
{
  "name": "محمد علي الأحمد",
  "employeeId": "40097",
  "idNumber": "2059538000",
  "company": "الشركة الثانية",
  "nationality": "مصري",
  "role": "Supervisor"
}
```

**الملاحظات:**
- ⚠️ **نفس الرقم الوظيفي** (40097) لكن في **شركة مختلفة**
- هذا **مسموح** لأنهما في شركات مختلفة
- رقم هوية مختلف (2059538000)

---

```json
  "company": "الشركة الأولى",
  "nationality": "سوري",
  "role": "Engineer"
}
```

**الملاحظات:**
- رقم وظيفي فريد: 40098
- نفس شركة أحمد (الشركة الأولى)
- دور: مهندس (Engineer)

---

### العامل 4: علي أحمد
```json
{
  "name": "علي أحمد",

  "nationality": "يمني",
  "role": "Worker"

```

**الملاحظات:**
- ⚠️ **بدون رقم هوية** (idNumber غير موجود)
- هذا **مسموح** (الحقل اختياري)
- لديه رقم وظيفي وشركة

---

### العامل 5: سعيد محمد
```json
{
  "name": "سعيد محمد",
  "nationality": "سودان",
  "role": "Worker"
}
```

**الملاحظات:**
- ⚠️ **بدون رقم وظيفي** (employeeId غير موجود)
- ⚠️ **بدون رقم هوية** (idNumber غير موجود)
- ⚠️ **بدون شركة** (company غير موجود)
- هذا **مسموح** (كل هذه الحقول اختيارية)
- الحقل الإجباري الوحيد: `name`

## 🎯 حالات الاختبار المغطاة

### ✅ حالات صحيحة:
1. **عامل كامل** (كل الحقول) - أحمد
2. **تكرار رقم وظيفي في شركة مختلفة** - محمد (نفس 40097)
3. **مهندس** (دور مختلف) - خالد
4. **بدون رقم هوية** - علي
5. **الحد الأدنى** (اسم فقط) - سعيد

### 📊 الإحصائيات المتوقعة:
- **إجمالي السجلات**: 5
- **صالح**: 5 ✅
- **غير صالح**: 0
- **لديه رقم وظيفي**: 4
- **لديه رقم هوية**: 3
- **لديه شركة**: 4

### ⚠️ التحذيرات المتوقعة:
```
الرقم الوظيفي 40097 مكرر لـ 2 أشخاص مختلفين
(هذا مسموح إذا كانوا في شركات مختلفة)
```

## 🧪 كيف تستخدم هذا الملف؟

### الطريقة 1: عبر الواجهة (موصى به)

1. شغّل التطبيق:
   ```bash
   npm run dev
   ```

2. افتح:
   ```
   http://localhost:9002/admin/import-workers
   ```

3. ارفع ملف `data/workers-sample.json`

4. راجع النتائج:
   - ✅ 5 سجلات
   - ✅ 5 صالح
   - ⚠️ تحذير واحد (تكرار 40097)

5. اضغط "استيراد 5 عامل"

### الطريقة 2: عبر CLI (للمطورين)

```bash
# التحقق أولاً
npm run validate:workers

# ثم الاستيراد
node scripts/import-workers-from-desktop.mjs data/workers-sample.json
```

## 📝 ملاحظات مهمة

### 1. الحقول الإجبارية
فقط `name` إجباري. باقي الحقول اختيارية:
- `employeeId` ← اختياري
- `idNumber` ← اختياري
- `company` ← اختياري
- `nationality` ← اختياري
- `role` ← اختياري (افتراضي: Worker)

### 2. تكرار الرقم الوظيفي
- ✅ **مسموح**: إذا كانت الشركة مختلفة
- ⚠️ **تحذير**: إذا كانت الشركة نفسها (قد يكون خطأ)

### 3. رقم الهوية
- يُفضّل 10 أرقام
- إذا كان أقل/أكثر، سيظهر تحذير فقط

### 4. الأدوار المتاحة
- `Worker` (افتراضي)
- `Supervisor`
- `Engineer`

## 🔄 إنشاء بياناتك الخاصة

يمكنك نسخ هذا الملف وتعديله:

```bash
cp data/workers-sample.json data/my-workers.json
```

ثم عدّل `my-workers.json` بالبيانات الحقيقية:

```json
[
  {
    "name": "اسم العامل",
    "employeeId": "رقم قصير",
    "idNumber": "10 أرقام",
    "company": "اسم الشركة",
    "nationality": "الجنسية",
    "role": "Worker"
  }
]
```
